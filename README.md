# Sentence Construction Tool 🧠

A frontend React + TypeScript app for practicing sentence construction (Sentence Construction Tool)

## 🚀 Features
- Fill-in-the-blank questions with 4 options
- 30-second timer per question
- Auto-advance or Next button
- Final feedback screen with score

## 🛠️ Tech Stack
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## 🧪 Run Locally

```bash
npm install
npm run dev
